<h2>👋 About</h2>

<p>I'm a <b>BS Computer Science student</b> at <b>PAF-IAST</b> who builds and ships full-stack web products for real businesses. My work centers on <b>e-commerce platforms with secure admin dashboards</b>: catalog and inventory management, order workflows, checkout, and cloud media, all deployed and live.</p>

<p>I care about type-safe code, validated inputs, sensible security defaults, and interfaces that feel fast on a phone, since that is where most of my clients' customers shop.</p>
